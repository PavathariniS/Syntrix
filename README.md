# SYNTRIX
### Network Security Monitoring Dashboard

CyberLab is a Python-based graphical application developed for learning network programming and cybersecurity concepts in a controlled laboratory environment.

## Technologies
- Python
- CustomTkinter
- Socket Programming
- Kali Linux
- Windows 11

## Tested Features
- TCP listener connectivity
- Windows-to-Linux network communication
- Multiple connection attempts
- Port conflict detection
- Network connectivity diagnostics
- Firewall status verification
- Server restart testing

## Project Status
Development and testing in progress.

## Security
This public project is intended for authorized, controlled cybersecurity learning and safe network testing.
